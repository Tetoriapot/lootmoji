るともじ / Demo v2

起動
  lootmoji_demo_v2 フォルダ内の index.html をブラウザで開いてください。
  HTML / CSS / Vanilla JavaScriptのみ。ネット接続・npm・ビルド・サーバーは不要です。
  このフォルダ内のファイルをまとめて移動・配布できます。

遊び方・操作
  上からモード選択 → パック開封 → 戦闘の順です。モード変更時はパック欄へ移動。
  最初は準備画面です。128パックを開封し「準備完了・出撃」で戦闘を開始します。
  開封結果を閉じると戦闘画面へ移動。戦闘画面にも出撃ボタンがあります。
  右側のキャラクターが自動で攻撃。敵のクリック・タップ・Enterで固定照準＋追加攻撃。
  敵一覧からの固定照準は停止中も可能。標準／危険敵／ボスの優先方針を選べます。
  P：停止／再開、M：MAX開封、X：固定解除（入力欄では無効）。
  危険時の自動減速は任意。直撃・回復・召喚予告、自爆・激昂突進の接近時に×0.5。
  危険がなくなると元の速度へ戻ります。
  敵の撃破でGOLDとPACKを獲得。5ウェーブでボス、5ステージで次のWORLDへ。
  パックの開封でカード効果が即反映され、組み合わせに応じてシナジーが解放されます。
  画面上部の「📦 MAX開封」は、1クリックで所持パックをすべて開封。
  スクロール中も上部に残ります。所持0個で無効化。PACK LABの選択数は変更しません。
  ×1 / ×10 / ×100 / ×1K / ×10K / ×100K / ×1M / MAX を選んで OPEN。
  所持数が選択数より少ない場合は、所持数だけ開封します。ボタンに実際の数を表示。
  GOLD 100で10パック購入できます。「＋1M PACKS / DEMO補給」は無料の動作体験用です。
  ⏩ は ×1 → ×2 → ×4。PAUSE / RESUMEで手動停止・再開。
  SEは最初のクリック・キー操作から鳴ります。戦闘上部と開封画面のSEボタンでミュート。
  戦闘上部のスライダーで音量0〜100%（初期35%）。0%でも完全に無音になります。
  FX MAX / LOWでエフェクト量を切り替え。LOWは火花・揺れを約30%に軽減します。
  開封中・結果詳細の表示中は戦闘と一時バフ・状態異常・ウェーブ制限時間が停止します。
  SKIPで即結果へ。ESCは演出中ならSKIP、結果表示中なら閉じます。
  SPACEもスキップ・閉じるに対応（ボタン上ではそのボタンを実行）。
  「直近の開封結果」を展開し、LAST OPENの「詳細を見る」で前回結果を再表示。全26種類の
  カード内訳、NEW、解放シナジー、開封前→後の10能力を確認できます。
  SSR以上 / NEWフィルターはカード演出だけに適用。全内訳は独立したレア／NEW絞り込みと
  レア順／枚数順／名前順の並べ替えに対応。0枚も掲載し、開封数・カード合計・レア合計を照合。
  すべての所持カードはCARD BUILDで確認できます。
  上部バーに大きなMAX開封と「戦闘・強化・ビルド・図鑑・？ガイド」を集約。
  戦闘中のホバー・フォーカス・タップで説明は自動表示しません。小さなⓘも撤去。
  「？ガイド」で調べたい操作・敵・能力・カード・キャラ・シナジーを選べます。
  ガイド中は戦闘と復帰カウント停止。閉じる／ESCで戻ります。スマホ・キーボード対応。
  ビルド・図鑑・照準リスト・被弾ログ・倍率や効率は必要な時だけ展開。
  文字サイズは従来どおり「大きめ」も選べます。
  専用の図鑑画面は「敵29種・ボス3種・カード26種・キャラ4種・味方シナジー8種・
  敵連携4種・攻略7項目」に分離。名前・能力・対策で検索可能。未遭遇・未入手も公開。
  図鑑の閲覧中は戦闘と復帰待機を停止。閉じる／ESCで元の操作へ戻ります。
  自キャラのHPが尽きた後は10秒の復帰待機。速度倍率に関係なく実時間で数えます。
  待機中は戦闘・WAVE制限時間が停止。パック開封やキャラ変更ができます。
  開封中・確認ダイアログ・手動停止・非表示タブでは復帰カウントも停止します。
  通常は10秒後に自動再出撃。ゆったり／挑戦は10秒後に出撃ボタンで再開できます。
  ビルドは保持。通常／挑戦はGOLD −18%、PACK −10%、WORLDは1つ戻ります。
  敵やボスの撃破、WAVE突破時には10秒待機は入りません。
  RESETは確認ダイアログの後、選択中の体験／遊び方の枠だけを初期化。他の枠は保持。
  SE音量・ミュート・演出・表示設定は保持します。
  自動保存・バックアップ・ゲスト試遊に対応しています（詳細は下記）。

保存と体験モード
  通常／DEMO × 通常／ゆったり／挑戦の6枠。体験・遊び方の変更は別枠への移動です。
  初期資源は各枠250 GOLD・128 PACK。DEMO補給はDEMO枠へ移動して100万追加。
  5秒ごと、主要操作時、タブを離れる時にlocalStorageへ保存します。
  再開時は同じ番号・種類のWAVEの冒頭で待機。HP・防壁・資源・カード・解放・記録を保持。
  敵・弾・WAVE内撃破数・残り時間・状態異常・一時バフ・直近開封画面は再生成／解除。
  進行中の開封もカード適用後に保存するため、再開時に重複付与しません。
  保存していた次WAVEの挑戦Lv予約は再開時には適用せず、次のWAVEまで保持。
  復帰待機の残り秒数も保存します。再読込後は残り時間の終了後、出撃ボタンで再開。
  更新前のセーブもそのまま読み込めます（復帰待機なしとして移行）。
  非表示タブや終了中のオフライン進行はありません。
  ゲストは保存プレイと別の一時データ。終了すると元の保存プレイへ戻ります。
  JSONバックアップは全枠・設定を出力。復元はバージョン・数値・ID・枚数合計を検証し、
  確認後に置き換えます。不正な保存データを起動時に自動で上書きしません。
  保存領域はブラウザ・ファイル場所に依存。移動・別ブラウザ・共有PCではバックアップ推奨。
  保存不可の場合は画面に表示。バックアップは手動でローカルファイルとして保存可能。
  画像保存もローカルのPNG出力のみで、外部への送信はありません。

遊び方プリセット
  通常：下記の強敵と制限時間を維持。死亡後は10秒で自動再挑戦。時間切れは即再挑戦。
  ゆったり：時間2倍。死亡・時間切れによる資源損失なし。同じWAVEで停止して再準備。
  挑戦：時間75%。死亡・時間切れの損失は通常と同じ。失敗後に停止して再準備。
  敵ステータス・抽選・報酬倍率は3プリセット共通。記録と進行は独立しています。

  ・cluster / line / rushの群れ。RUSHは5秒間スポーン頻度3倍、ELITEは高耐久、
    SWARMは低HPの敵が上限まで出現。特殊ウェーブはランダム順の一巡方式。
  ・3タイプのシールド付きボス＋連携する随伴2体＋通常取り巻き4体。
    登場時スロー、3→5発弾幕、HP40%以下で激昂、予告付き特殊行動と中断。
  ・ウェーブ制限時間、予告付きダイレクトアタック、高速自爆敵、DANGERの3段階表示。
  ・着弾する弾道、CRIT、死亡、パック吸引、雷、連鎖爆発、ブラックホール。
  ・0.7秒以内の連続撃破でKILL CHAIN。10 / 25 / 50 / 100で演出が強化。
  ・26種類のカード（SECRETは6種類）、8種類のシナジー。解放通知中は戦闘を継続。
  ・少数開封はカード表示、中規模は扇状表示、大規模は高速カウント。
    100万 / MAXには専用演出。UR・SECRETには専用の光と亀裂演出。
  ・100%以上の能力上昇はHUGE BOOST。NEWは開封前の所持状態と比較。
  ・PC・スマホ幅に対応。モーダル内スクロール、キーボードのフォーカス制御、
    OSの「動きを減らす」設定にも対応しています。

SE・エフェクト強化
  ブラウザのWeb Audioで21系統の短いSEを生成。外部音源・BGMはありません。
  通常弾（キャラ別）、着弾、会心、撃破、爆発、パック吸引、敵射撃、被弾、
  防御、カウンター、チェイン、ボス、特殊ウェーブ、操作、開封、集計カウント、
  レア、SECRET、シナジー、開封チャージ、封印破壊の音を用意しています。
  発音間隔の制限、同時24音までの上限、音量圧縮を使用。
  タブ非表示・PAUSE・RESETで残っているSEを停止します。
  Web Audioがないブラウザでは音なしでプレイできます。
  火花・弾の軌跡・衝撃波・CRITICAL/BOOM文字・撃破破片・開封の光線を追加。
  会心・ボス撃破に短いスロー。画面フラッシュと揺れは短時間に限定しています。
  Canvas粒子は最大360、従来のDOMエフェクト上限も維持。描画ループは1本です。

豪華なパック開封
  CHARGING → SEAL BREAK → LOOT CASCADE → RARE REVEALの4段階。
  浮遊するパック、回転光線・光の軌道、封印破壊、紙吹雪、ホイル加工風カードを表示。
  実際に取得したカードから1種を大きく公開。URはピンク、SECRETは虹色の特別演出。
  SSR以上・NEWフィルターは大きなカードにも適用。対象なしならBUILD UPGRADED表示。
  豪華：通常2.1秒、100個以上3.2秒、1万個以上4.3秒、100万個以上5.6秒。
  MAXも実際の開封数で長さを決定。初入手・UR以上中心は対象なしの場合0.22秒。
  高速は0.22秒。ただし新規SECRETは最低3.2秒の演出を残します。抽選は全設定共通。
  SKIP・ESCでいつでも即結果へ。音量・ミュート設定も共有します。
  紙吹雪は最大48個で、パック数に比例して増えません。FX LOWでは最大14個。
  OSの動きを減らす設定では0.18秒で完了し、紙吹雪・回転・反転を省略します。

ウェーブの制限時間
  通常プリセット：NORMAL 45秒 / RUSH 35秒 / ELITE 50秒 / SWARM 40秒 / BOSS 75秒。
  上部の時計とゲージで残り時間を表示し、10秒以下で赤い警告とSE。
  開封・PAUSE・タブ非表示中は停止。戦闘速度や戦闘スローと同じ時間で進みます。
  時間切れはGOLDを10%失い、HP・シールドを回復して同じ種類・番号のWAVEを再挑戦。
  PACK・カード・解放キャラ・敵強化は保持。敵・弾・状態異常・WAVE内撃破数はリセット。
  期限と同じ更新でクリア条件を満たした場合はクリアを優先します。

HARD PRESSURE（敵の強化）
  以前の版に対して、基礎HP ×1.8、移動速度 ×1.22。
  WORLDごとのHP成長は ×1.65 → ×1.9、ステージ補正も強化しています。
  通常の増援は0.65秒ごとに最大4体（以前は0.9秒ごと3体）。RUSHはさらに頻度3倍。
  接触・遠距離・ボス弾幕のダメージをさらに1.75倍に強化。
  接触ダメージは通常 (10＋WORLD×2)×1.75、ボス (50＋WORLD×5)×1.75。
  遠距離ダメージは基礎威力×(1＋WORLD×0.12)×1.75。
  さらに敵強化の攻撃倍率を乗算。ELITEは接触・射撃ともさらに1.4倍。
  WORLD 1で通常接触21、ボス接触96.25、ARCHERの1発13.72。
  ボスは初期WORLD・STAGEで最大HP 4,320、シールド2,592（HPの60%）。
  シールドは先にダメージを吸収し、超過分だけHPへ。壊すとSHIELD BREAK演出。
  HP40%以下で激昂してシールドを1回だけ全再展開。移動 ×1.5、弾幕頻度 ×1.6。
  4.2秒ごとの3連弾が、激昂中は5連弾＋威力 ×1.3になります。
  左58%付近で停止して射撃、激昂すると68%付近まで押し上げます。
  弾幕1発の威力は (8＋WORLD×3)×1.75×敵強化倍率（WORLD 1で19.25）。
  強化した敵に合わせて基礎GOLD報酬も増やしています。

コインでキャラクターを解放（COMBAT HQ）
  🧙 COLLECTOR / バランス / 初期解放
     通常の自動攻撃。補正なし。
  🥊 BRAWLER / カウンター / 750 GOLD
     長所：被ダメージ35%軽減、被弾・ガード・シールド吸収時にDMG ×4の範囲反撃。
     短所：通常DMG ×0.85、APS ×0.65。反撃できない場面の突破速度が低下。
     反撃は0.6秒に1回。致死ダメージには反撃しません。
  🧝‍♀️ NOVA / 広範囲 / 2,000 GOLD
     長所：DMG ×1.2、通常攻撃の着弾時に広範囲へ120%の追加ダメージ。
     短所：APS ×0.65、BARRIER・AEGISを含む全シールド容量 ×0.6。
  🤠 RANGER / 射撃 / 5,000 GOLD
     長所：APS ×1.9。遠距離・直撃敵を優先し、2体へ射撃（2体目は65%威力）。
     短所：DMG ×0.75、被ダメージ ×1.35（毒を含む、軽減・シールドの前に適用）。
  解放と同時に交代。解放後の交代は無料で、カード効果は共有されます。
  交代してもHP・シールド・反撃クールダウンは回復しません。
  NOVAへの交代で容量を超えるシールドは失われ、他キャラに戻しても復元されません。
  COMBAT HQに長所を緑、短所を赤で常時表示しています。
  解放は現在の保存枠に保持。死亡・リロードでも残り、この枠のRESETで初期化します。
  交代・解放前に確認画面で実数と失われる防壁を表示します。

コインで敵を強化（ENEMY OVERDRIVE）
  上限をLv.30からLv.999へ拡張。最初は500 GOLD。
  Lv.30までの1段階は敵HP ×3、ATK ×1.12、GOLD ×1.6、PACK ×1.25。
  Lv.31以降はHP ×1.16、ATK ×1.04、GOLD ×1.012、PACK ×1.008。
  費用は最高解放LvをLとして、floor(500 × 1.8^min(L,30) × (1+max(0,L-30)/20)^2)。
  「＋1」「＋10」「MAX強化」は資金内で買える段階だけまとめて解放。確認画面に
  到達Lv・合計費用・現在からの倍率を表示。キャンセル可能。上限後は購入不可。
  ボスを含め、その場にいる敵にも残HP・シールドの比率を保って即反映します。
  購入は最高解放Lvから指定分を解放して即適用。挑戦Lvを下げている場合も到達Lvを適用。
  解放済みLvは無料で選び直せます。次WAVE（失敗後の再挑戦を含む）から適用。
  残っている敵のHP／防壁も残量比率を保って変更。コインの払い戻しはありません。
  高Lvでも内部値は有限に保ちます。資源上限は9,007,199,254,740,991、能力上限は1e90。
  能力上限に到達するWORLDではHP等の成長が頭打ちになります。Lvを下げると
  元の基礎HPから再計算し、残HP／防壁の割合を維持します。
  敵1体の報酬増加は毎秒収益増を意味しません。射手の撃破時間の目安も表示。
  実測収益は現在セッションの撃破報酬／ゲーム内時間、消費控除前。Lv変更時にリセット。

遠距離敵
  🏹 BONE ARCHER : 左から43%付近で停止し、2.5秒ごとに矢を撃ちます（基礎威力7）。
  🧛 HEX CASTER  : 左から34%付近で停止し、3.2秒ごとに魔法弾を撃ちます（基礎威力13）。
     命中で5秒間、最終APSを30%低下させます。
  🦑 VOID LANCER : 左から40%付近で停止し、3.4秒ごとに貫通弾（基礎威力16）。
     軽減後のダメージの60%がシールドを通り抜けHPへ。残り40%はシールドで吸収。
     シールド不足分もHPへ通ります。ARMOR・BRAWLERの軽減と完全ガードは有効。
  🧟 PLAGUE SHAMAN : 左から31%付近で停止し、4.4秒ごとに毒弾（基礎威力10）。
     命中で6秒間の毒。毎秒、命中弾の軽減前ダメージの30%を受けます。
     毒の間はHPの毎秒回復が50%低下。シールド回復・AEGIS全補充には影響しません。
  貫通射手はWORLD 1のWAVE 3以降（またはSTAGE 2以降）、毒使いはWORLD 2以降。
  ARCHERは最初のウェーブから、CASTERはWORLD 2以降に登場。
  発射直前は発光してFIRE表示。赤い敵弾がプレイヤーに届くと被弾します。
  CASTER・ELITE・WORLD 3以降の射手は2連射（2発目は65%威力）。
  RANGERなら遠距離敵を優先。停止・開封中は敵弾も止まります。

ダイレクトアタック・高速自爆

  ボスタイプはWORLDとSTAGEに応じて切り替わります。元のHP・防壁・激昂弾幕に加え、
  1.5秒の予告後に特殊行動。予告中にボスの防壁を破壊すると特殊行動を中断し、
  3秒間、ボスへのダメージ1.35倍。次回の特殊行動までの時間も最初から数え直します。
  特殊行動・予告・弱体時間はゲーム内時間。開封／手動停止／ガイド／図鑑で停止。
  🏰 堡塁王：防壁役＋結晶が随伴。9秒ごとに最大HP15%分の防壁を補充（上限は元の防壁）。
     再装填は最大3回。先に結晶→防壁役を狙い、共鳴防壁を解除。
  🐝 群体皇后：女王＋鼓手が随伴。8秒ごとに雑兵3体、ボス自身の配下は最大6体。
     女王で凶暴化、鼓手で加速。主を倒すか、NOVA・SPLASHで群れを処理。
  👁️ 虚眼の審判者：呪い役＋ジャマーが随伴。10秒ごとに80%貫通直撃＋3秒の防壁回復停止。

  ボスを討伐すると、そのボスの随伴・配下と随伴が呼んだ雑兵も消去。

  防壁量・激昂再展開・特殊行動の残り時間は戦闘フィールド外に表示します。

状態異常
  SLOWは攻撃速度低下、POISONは毒＋HPの毎秒回復低下。
  戦闘の能力表示の下に残り秒数を表示。詳細は「？ガイド」から確認できます。
  シールドで弾を全吸収しても付与されますが、PARRYの完全ガードは付与を防ぎます。
  毒の継続ダメージには防御軽減とシールドが有効。付与済みの毒は完全ガード不可。
  同種は重複せず再被弾で時間を更新。毒は強い威力だけ保持し、毎秒の間隔も維持。
  発射した敵を倒しても弾・付与済みの状態異常は残り、再出撃・RESETで解除。
  PAUSE・開封中は残り時間と毒ダメージが止まり、戦闘速度×2/×4に合わせて進みます。

実装メモ
  1本のrequestAnimationFrameで戦闘・演出・開封カウンターを更新します。
  DOM上限は敵36、projectile40、damage60、particle80。死亡表現もparticle上限内。
  エフェクトが上限を超えると古いものを削除。連鎖撃破はキュー処理です。
  開封はレアリティ→カードの二項分布による集計。巨大配列・個別タイマーは作りません。
  少数・希少事象は直接抽選または逆関数法、十分大きな母数は正規近似を使用。
  枚数は常に整数で、レアリティ別・カード別の合計は開封数と一致します。
  強化カードは大量取得時に伸び方が緩やかになります。カードによる基礎APSは最大30、
  キャラ補正・LAST STANDを含めて最大60。100万開封後もNaN/Infinityになりません。
  資源・カード枚数はNumber.MAX_SAFE_INTEGERまで。能力値上限は1e90。
  数字の略記はK/M/B/T/Qa/Qi/Sx/Sp/Oc/No/Dc、さらに大きい値は指数表記。
  settings.pauseDuringPacksで将来の「開封中も戦闘」設定を分離しています。
