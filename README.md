# るともじ

絵文字の敵を倒し、パックからカードを集めてビルドを育てるブラウザゲーム。

**[ゲームを遊ぶ](https://tetoriapot.github.io/lootmoji/)**

モード選択 → パック開封 → 戦闘の順に操作します。最初の128パックを開封し、戦闘画面の「準備完了・出撃」で開始します。開封せずに出撃することもできます。

- 自動戦闘と固定照準、4キャラクター、26種類のカード、8シナジー
- シールド付きボス、遠距離・貫通・デバフ・直撃・高速自爆の敵
- 仲間の回復、雑兵の召喚、防壁吸収、装甲から激昂突進に切り替わる敵
- 防壁付与・分裂・防壁回復妨害・貫通狙撃・仲間加速の敵を追加
- 中継・女王・結晶・呪い役による敵連携4種。中心や条件を崩すと解除
- 堡塁王・群体皇后・虚眼の3タイプのボス、連携する随伴、予告付き特殊行動と中断
- 敵／ボス／カード／キャラ／味方シナジー／敵連携の専用図鑑と検索・攻略ヒント
- 敵強化はLv.999まで。＋1／＋10／買えるだけのMAX強化
- 大きなMAX開封と移動バー、詳細の折りたたみ。説明は「？ガイド」に集約
- ビルドはコンパクトなシナジー・所持カード一覧。カード欄はスクロール可能
- 自キャラが倒された後は10秒待機。その間にパック開封やキャラ変更が可能
- 一括MAX開封、SE、開封演出と戦闘エフェクトの設定
- 通常／DEMO × ゆったり／通常／挑戦の6つの独立した保存枠
- ローカル保存、ゲスト試遊、JSONバックアップ／復元。失敗理由は操作場所と固定バーに表示
- カード図鑑、キャラ別記録、実績、ビルド／開封結果のPNG保存

P：停止／再開、M：MAX開封、X：照準解除。詳細は [README.txt](README.txt) を参照してください。

## 今回の操作改善（2026-10-26）

レビューの優先順位1〜10を実装しました。詳しい操作はREADME.txt、確認項目はTASKS.mdに記載しています。

- コイン不足額、使用中、上限到達を表示。ビルド項目はEnterでも図鑑を開けます。
- 6つの保存枠の移動先を表示し、戦闘欄にもモードと敵Lvを表示します。
- 文字設定を上部から開けます。シナジー図鑑では必要数・所持数・不足数を確認できます。
- 優先する敵を戦闘欄の近くで選べます。連携の中心を選ぶと、支援を受ける敵を表示します。
- 解放済みの敵Lvを数値で予約できます。概算の火力、消費前の撃破報酬、計測中の残高差を分けて表示します。
- 10秒の復帰待機に敗因、再準備ボタン、カウントが止まっている理由を表示します。
- 開封欄から演出設定へ移動できます。結果に主な能力変化、新規カード数、新規シナジーを表示します。
- 既存の実績・カード・シナジーから目標を1件固定できます。保存枠ごとに記録し、再開時にも表示します。

保存キーと形式のバージョンは変更していません。旧セーブには「固定目標なし」を適用し、資源やカードを引き継ぎます。

## ローカルで遊ぶ

このリポジトリをダウンロードし、`index.html` をブラウザで開きます。
ネット接続、npm、ビルド、サーバーは不要です。

セーブはブラウザの保存領域に保存されます。ローカル版と公開版、別のブラウザへ移る場合は、
ゲーム内のバックアップ保存／復元を使用してください。

## GitHub Pages

`main` ブランチのルートを配信します。`.nojekyll` により静的ファイルをそのまま公開します。
`index.html`、`style.css`、`script.js` を更新して `main` にpushすると公開版へ反映されます。
